# zero-minimap

Hides the minimap when you're on foot. Shows it automatically when you get in a vehicle.

## Install

1. Drop this folder into your `resources` directory.
2. Add `ensure radar` to your `server.cfg`.
3. Restart the server.

## Usage

| Command  | Description |
|----------|-------------|
| `/radar` | Toggle the minimap on/off while on foot |

The minimap always shows in a vehicle, regardless of the toggle.
